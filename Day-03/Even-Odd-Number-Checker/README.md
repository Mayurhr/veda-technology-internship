# Even and Odd Number Checker

## Description

This is my Day 3 task for the Veda Technology Python Programming internship.

The program accepts a number from the user and checks whether the number is even or odd.

## Objective

The objective of this task is to practice conditional statements and the modulus operator in Python.

## Technologies Used

- Python 3
- Visual Studio Code

## How It Works

The program takes an integer from the user.

It uses the modulus operator `%` to find the remainder when the number is divided by 2.

- If the remainder is 0, the number is even.
- Otherwise, the number is odd.

## Example

For the number 10:

```text
10 % 2 = 0
