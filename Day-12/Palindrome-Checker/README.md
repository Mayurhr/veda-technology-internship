# Palindrome Checker

## Day 12 - Veda Technology Python Internship

This project is a Python program that checks whether a word or sentence is a palindrome.

## Objective

Practice string manipulation and comparison logic.

## Description

The program accepts a word or sentence from the user and determines whether it reads the same forwards and backwards.

The input is normalized by converting it to lowercase and ignoring unnecessary spaces.

## Features

- Accepts a word or sentence
- Converts input to lowercase
- Removes spaces
- Reverses the string using slicing
- Checks whether the original and reversed strings are equal

## Tool Used

- Python

## Concepts Used

- Strings
- String methods
- String slicing
- `lower()`
- `replace()`
- `[::-1]`
- Conditional statements

## How to Run

Run the following command:

python palindrome_checker.py

## Example

Input:
Madam

Output:
It is a palindrome.

Input:
Python

Output:
It is not a palindrome.

## Conclusion

This project helped me understand string normalization, string slicing, reversal, and comparison in Python.
