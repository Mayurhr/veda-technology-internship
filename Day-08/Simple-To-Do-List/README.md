# Simple To-Do List

This is a simple command-line To-Do List application created using Python as part of my Veda Technology internship.

## Description

The program allows the user to add, view, update, and remove tasks from a To-Do List.

## Features

- Add a task
- View all tasks
- Update a task
- Remove a task
- Exit the program
- Handles invalid menu choices

## Technologies Used

- Python

## Concepts Used

- Lists
- Loops
- Conditions
- Functions
- User input
- CRUD operations

## How to Run

Run the following command:

```bash
python todo_list.py
