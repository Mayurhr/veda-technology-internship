# Student Grade Calculator

## Description

This is my Day 4 task for the Veda Technology Python Programming internship. In this task, I created a simple student grade calculator in Python. The program accepts marks for multiple subjects and calculates the total marks, percentage, and grade.

## Objective

The main objective of this task is to practice conditions, arithmetic operations, loops, and input validation in Python.

## Technologies Used

Python 3 was used to create the program. I used Visual Studio Code to write and run the program.

## Problem Statement

The program should accept marks for multiple subjects and calculate the total marks and percentage. Based on the percentage, it should assign a grade. The program should also check that the entered marks are between 0 and 100.

## Implementation

The program first asks the user for the number of subjects. It then accepts marks for each subject and adds them to calculate the total marks. The percentage is calculated using the total marks and number of subjects.

The program uses if, elif, and else conditions to assign a grade based on the percentage.

## Grade Criteria

A+ : 90% and above

A : 80% to 89%

B : 70% to 79%

C : 60% to 69%

D : 50% to 59%

F : Below 50%

## Input Validation

The program checks whether the entered marks are between 0 and 100. If the user enters a value outside this range, the program asks for the marks again.

## Sample Input

Number of subjects: 5

Subject 1: 85

Subject 2: 78

Subject 3: 92

Subject 4: 88

Subject 5: 80

## Sample Output

Total Marks: 423.0

Percentage: 84.60%

Grade: A

## Testing

I ran the program in the VS Code terminal and tested it with different marks. I also tested marks outside the allowed range. The program correctly asked for valid marks when an invalid value was entered.

## What I Learned

Through this task, I learned how to use loops, conditional statements, arithmetic operations, and input validation in Python. I also learned how to calculate percentage and assign grades based on conditions.
