# Simple Calculator

## Description

This is a simple Python calculator program created as Day 2 of my Veda Technology internship.

The program takes two numbers from the user and performs addition, subtraction, multiplication, division, and modulus operations.

## Objective

The objective of this task is to practice arithmetic operators, user input, functions, and basic program logic in Python.

## Technologies Used

- Python 3
- Visual Studio Code

## Operations

The calculator supports:

- Addition
- Subtraction
- Multiplication
- Division
- Modulus

## Division by Zero

The program checks whether the second number is zero before performing division or modulus.

If the second number is zero, it displays an appropriate message instead of causing an error.

## How to Run

Open the project folder in VS Code and run:

```bash
python calculator.py
```
