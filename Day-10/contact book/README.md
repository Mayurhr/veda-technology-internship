# Contact Book Using Dictionaries

## Day 10 - Veda Technology Internship

This project is a simple command-line contact book created using Python dictionaries.

## Description

The program allows users to add, search, update, delete, and view contact information.

## Objective

To learn dictionaries and practical key-value data management.

## Features

- Add a contact
- Search a contact
- Update contact information
- Delete a contact
- View all contacts
- Handle duplicate contacts
- Menu-driven interface

## Tools Used

- Python

## Concepts Used

- Dictionary
- Key-value pairs
- if-elif-else
- while loop
- for loop
- Functions/operations
- User input

## How to Run

Run the following command:

python contact_book.py

## Example

The user can select an option from the menu and manage contacts.

## Conclusion

This project helped me understand how Python dictionaries can be used to store and manage contact information efficiently.
