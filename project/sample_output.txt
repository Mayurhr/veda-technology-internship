----------------------------------------
OBJECT-ORIENTED PROGRAMMING
----------------------------------------

The project uses classes for the main entities:

Program
Service
Customer
Inquiry

Objects are created during data entry and
converted into dictionaries using to_dict()
before being stored in JSON files.


----------------------------------------
DATA STORAGE
----------------------------------------

JSON files:

data/programs.json
data/services.json
data/inquiries.json

CSV storage is also supported through the
storage module.
