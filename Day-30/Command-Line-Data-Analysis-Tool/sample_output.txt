$ python data_analysis_cli.py --help
usage: data_analysis_cli.py [-h] [--summary] [--filter COLUMN VALUE]
                            [--group COLUMN] [--stats COLUMN]
                            csv_path

A simple command-line tool to analyze CSV data using Pandas.

positional arguments:
  csv_path              Path to the CSV file to analyze (required, not
                        hardcoded).

options:
  -h, --help            show this help message and exit
  --summary             Show an overview of the dataset (rows, columns,
                        preview).
  --filter COLUMN VALUE
                        Filter rows where COLUMN equals VALUE, e.g. --filter
                        region North
  --group COLUMN        Group rows by COLUMN and show counts/totals, e.g.
                        --group category
  --stats COLUMN        Show statistics (mean, min, max, etc.) for a numeric
                        COLUMN, e.g. --stats sales

Examples:
  python data_analysis_cli.py sample_data.csv --summary
  python data_analysis_cli.py sample_data.csv --filter region North
  python data_analysis_cli.py sample_data.csv --group category
  python data_analysis_cli.py sample_data.csv --stats sales
