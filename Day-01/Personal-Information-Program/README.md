# Personal Information Program

## Description
This is a simple Python program that asks the user for some basic personal
information (name, age, city, college, course and year) and then displays
it back in a clean, formatted profile using f-strings.

## Objective
This task was done to practice some basic Python concepts:

- Variables
- The input() function
- Type conversion (converting text input into integers)
- Formatted output using f-strings

## Technologies Used
- Python 3

## How to Run
1. Open the project folder in VS Code.
2. Open a terminal in VS Code.
3. Run the program with:

```
python personal_information.py
```

4. Enter the requested details when prompted.

## Inputs

| Input   | Type    | Purpose                     |
|---------|---------|------------------------------|
| Name    | String  | User's name                 |
| Age     | Integer | User's age                  |
| City    | String  | User's city                 |
| College | String  | College name                |
| Course  | String  | Course name                 |
| Year    | Integer | Academic year of study      |

## Output
After all the inputs are entered, the program prints a formatted
"Personal Profile" section showing all the details that were entered.
