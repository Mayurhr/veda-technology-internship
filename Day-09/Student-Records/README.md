# Student Records

This is a simple Python program created as part of my Veda Technology internship.

## Description

The program stores student names and marks in lists. It displays student records, finds the highest and lowest marks, sorts the marks, and allows the user to search for a student.

## Features

- Store student names and marks
- Display student records
- Find highest score
- Find lowest score
- Sort marks
- Search for a student

## Tools Used

- Python

## Concepts Used

- Python lists
- for loop
- max()
- min()
- sorted()
- index()
- User input
- Searching and sorting
