# Word and Character Counter

## Day 11 - Veda Technology Internship

This project is a simple Python program that analyzes a paragraph and counts characters, words, sentences, and spaces.

## Objective

Practice string manipulation and basic text processing.

## Features

- Count characters
- Count words
- Count sentences
- Count spaces
- Handle empty input

## Tools Used

- Python

## Concepts Used

- Strings
- len()
- split()
- count()
- for loop
- if statement

## How to Run

Run:

python word_character_counter.py

## Example

Enter a paragraph and the program will display its text statistics.

## Conclusion

This project helped me understand Python string operations and basic text analysis.
