# Multiplication Table

## Description

This is my Day 6 task for the Veda Technology Python Programming internship. I created a simple Python program that accepts a number and generates its multiplication table up to a limit given by the user.

## Objective

The objective of this task was to practice for loops and formatted output in Python.

## Technologies Used

Python 3

## How the Program Works

The program asks the user to enter a number and the limit up to which the multiplication table should be displayed.

A for loop is used to generate the table from 1 to the given limit.

## Features

- Accepts a number from the user
- Accepts a table limit
- Uses a for loop
- Displays the multiplication table clearly

## Sample Output

The program was tested with different numbers and limits.

Example:

Enter a number: 5
Enter the limit: 10

Multiplication table of 5

5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50

## Testing

I tested the program with three different numbers to check whether the multiplication tables were generated correctly.
