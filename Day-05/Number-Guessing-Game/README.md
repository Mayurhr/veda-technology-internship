# Number Guessing Game

## Description

This is my Day 5 task for the Veda Technology Python Programming internship. I created a simple number guessing game using Python.

The program generates a random number between 1 and 100. The user keeps guessing until the correct number is found.

## Objective

The objective of this task was to practice loops, conditions, random number generation, and user interaction in Python.

## Technologies Used

Python 3

## How the Program Works

The program generates a random number between 1 and 100 using the random module.

The user enters a guess and the program tells whether the guess is too high or too low.

The number of attempts is counted until the user guesses the correct number.

## Features

- Generates a random number
- Accepts user guesses
- Gives high or low hints
- Counts the number of attempts
- Stops when the correct number is guessed

## Sample Output

The program was tested by entering different guesses until the correct number was found.

Example:
